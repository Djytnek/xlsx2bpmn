# Приём сотрудника на работу

Кандидат приносит в отдел кадров пакет документов. Кадровик оформляет
трудовой договор на основании этих документов. Дальше одновременно
запускаются две ветки: бухгалтерия заводит карточку сотрудника по трудовому
договору, а системный администратор по нему же создаёт учётную запись
и выдаёт логин. Когда обе ветки закончены, кадровик готовит приказ о приёме
и подшивает его в личное дело. Процесс завершён.
