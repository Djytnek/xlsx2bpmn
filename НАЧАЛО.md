# Начало

Эта страница — на пять минут. Всё остальное в [README.md](README.md), туда
загляните потом.

**Что делает программа.** Вы описываете процесс обычной таблицей — кто и что
делает по шагам. Программа рисует из неё схему: картинку и файл, который
открывается в редакторах схем. И умеет обратно: из готовой схемы сделать
таблицу.

**Что нужно.** Linux с терминалом и Python версии 3.10 или новее. Интернет —
только один раз, при установке.

---

## 1. Поставить. Делается один раз

Откройте терминал и вводите команды по одной, сверяя ответ.

```bash
python3 --version
```

Должно ответить `Python 3.10` или больше — 3.11, 3.12, 3.13 тоже подходят.

```bash
cd ~
git clone https://github.com/Djytnek/xlsx2bpmn.git
python3 -m pip install --user ~/xlsx2bpmn
```

Последняя строка ответа должна быть `Successfully installed ... xlsx2bpmn-1.14.0`.

> Ответило `error: externally-managed-environment`? Значит **ничего
> не установилось**, ваш Linux так защищает системные пакеты. Повторите
> ту же команду с добавкой в конце:
> `python3 -m pip install --user --break-system-packages ~/xlsx2bpmn`

Теперь разрешим запускать команду по имени:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && export PATH="$HOME/.local/bin:$PATH"
```

Ответом будет тишина — так и должно быть.

Проверяем:

```bash
xlsx2bpmn --version
```

Должно ответить `xlsx2bpmn 1.14.0`. **Вот это и есть успех.** Если ответило
`command not found` — вернитесь на шаг назад, к строке про `PATH`.

## 2. Первая схема. Две минуты

Скопируйте **весь блок целиком**, вместе со строчками `EOF`, вставьте
в терминал и нажмите Enter:

```bash
cat > Отпуск.txt <<'EOF'
id|name|type|pool|lane|next
s|Нужен отпуск|startEvent|ООО «Ромашка»|Сотрудник|t1
t1|Написать заявление|userTask|ООО «Ромашка»|Сотрудник|t2
t2|Согласовать|userTask|ООО «Ромашка»|Руководитель|t3
t3|Оформить приказ|userTask|ООО «Ромашка»|Кадры|e
e|Отпуск оформлен|endEvent|ООО «Ромашка»|Кадры|
EOF
```

Вы только что создали таблицу процесса. Теперь схема:

```bash
xlsx2bpmn Отпуск.txt -o Отпуск.png
```

Ответит:

```
OK -> Отпуск.png  элементов 5, потоков 4, сообщений 0, пулов 1, раскладка: bpmn-auto-layout
```

Рядом появилась картинка `Отпуск.png`. Откройте её двойным щелчком или
командой `xdg-open Отпуск.png` — увидите схему с тремя дорожками:
«Сотрудник», «Руководитель», «Кадры».

---

## 3. Как читается таблица

Шесть колонок, разделённых чертой `|`. Каждая строка — один шаг процесса.

| Колонка | Что писать |
|---|---|
| `id` | короткое имя строки, латиницей: `s`, `t1`, `e`. Нужно, чтобы на строку ссылаться |
| `name` | название шага человеческими словами — оно попадёт на схему |
| `type` | что это за шаг, см. ниже |
| `pool` | название организации. Обычно у всех строк одно и то же |
| `lane` | роль или отдел, кто делает шаг. Для каждой роли будет своя полоса |
| `next` | `id` следующего шага. У последнего шага пусто |

Типов шагов достаточно четырёх:

| `type` | Что означает | Как выглядит |
|---|---|---|
| `startEvent` | процесс начался | кружок |
| `userTask` | человек что-то делает | прямоугольник |
| `exclusiveGateway` | вопрос, развилка | ромб |
| `endEvent` | процесс закончился | жирный кружок |

**Развилка.** У ромба в колонке `next` пишут несколько ответов через точку
с запятой, а подпись ветки — в квадратных скобках:

```
g|Сумма больше 100 000?|exclusiveGateway|ООО «Ромашка»|Бухгалтер|t1 [Да]; *t2 [Нет]
```

Звёздочка `*` помечает ветку «во всех остальных случаях». Она нужна, иначе
программа отругается, что не знает, куда идти.

**Разделитель только `|`.** Запятые и точки с запятой между колонками
не годятся — программа скажет об этом прямо.

## 4. Три команды на каждый день

Пусть ваш файл называется `Процесс.xlsx` или `Процесс.txt` — годится и то,
и другое.

**Получить картинку:**

```bash
xlsx2bpmn Процесс.xlsx -o Процесс.png
```

**Получить схему для редактора** — файл `.bpmn`, его можно открыть
в Camunda Modeler или перетащить на сайт demo.bpmn.io и править мышкой:

```bash
xlsx2bpmn Процесс.xlsx
```

**Превратить готовую схему обратно в таблицу:**

```bash
bpmn2xlsx Процесс.bpmn
```

Круг замкнут: таблица → схема → таблица возвращает ровно ту же таблицу,
ничего не теряя.

**Не хочется набирать таблицу с нуля?** Возьмите готовый шаблон с примером
и правьте его в Excel или LibreOffice:

```bash
xlsx2bpmn --template Процесс.xlsx
```

## 5. Если не получилось

Программа не молчит: она называет строку и говорит, что не так. Самое частое:

| Ответ на экране | Что случилось |
|---|---|
| `command not found` | установка прошла, но терминал не знает команду. Шаг про `PATH` в разделе 1 |
| `error: externally-managed-environment` | не установилось ничего. Повторить с `--break-system-packages` |
| `в пуле 'ООО' нет startEvent` | в таблице нет строки с `type` = `startEvent`. Так же и про `endEvent` |
| `next ссылается на несуществующий id 't9'` | опечатка: в колонке `next` стоит имя строки, которой в таблице нет |
| `не найден разделитель '\|'` | колонки разделены запятыми. Нужна вертикальная черта |
| `это не BPMN-диаграмма` | таблицу подали команде `bpmn2xlsx`. Таблицу превращает в схему `xlsx2bpmn`, наоборот — `bpmn2xlsx` |
| `No such file or directory` | опечатка в имени файла или вы не в той папке. `ls` покажет, что рядом |

Ничего не испортится: программа только читает вашу таблицу и создаёт новые
файлы рядом.

## Уже есть регламент в Word или PDF?

Набирать таблицу руками тогда не нужно: документ читает нейросеть, а утилита
проверяет её работу и подсказывает, что поправить. Весь путь по шагам —
в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Что дальше

Это была самая простая часть. Когда понадобится больше, в [README.md](README.md)
есть разделы про:

- **документы** — какие бумаги рождаются на каком шаге;
- **подпроцессы** — шаг, внутри которого спрятан свой процесс, и команда
  `--all-levels`, раскладывающая каждый уровень отдельными файлами;
- **несколько организаций** на одной схеме и переписку между ними;
- **обновление** программы, когда выйдет новая версия.

Обновляться, кстати, стоит: номер версии в начале README должен совпадать
с тем, что отвечает `xlsx2bpmn --version`.
