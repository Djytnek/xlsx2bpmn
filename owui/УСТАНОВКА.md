# Установка «BPMN-схема» в Open WebUI

Инструкция рассчитана на то, что вы ничего не знаете про Python и командную
строку. Каждый шаг — это либо нажать кнопку, либо скопировать готовый блок
целиком и вставить. Придумывать ничего не нужно.

Занимает около 20 минут.

**Что получится.** В списке моделей Open WebUI появится «BPMN-схема».
Выбираете её, вставляете описание процесса обычным текстом — получаете
готовую схему картинкой, файл для BPMN-редактора и возможность править схему
словами прямо в переписке.

---

# Шаг 1. Создать ключ для скачивания кода

Код лежит в закрытом хранилище на GitHub, поэтому нужен пропуск.

1. Откройте **github.com** и войдите в свою учётную запись.
2. Нажмите на **свой значок** в правом верхнем углу → **Settings**.
3. В меню слева пролистайте в самый низ → **Developer settings**.
4. Слева выберите **Personal access tokens** → **Fine-grained tokens**.
5. Нажмите зелёную кнопку **Generate new token**.
6. Заполните:
   - **Token name**: `owui`
   - **Expiration**: `90 days`
   - **Repository access**: выберите **Only select repositories**, затем в
     появившемся списке — **xlsx2bpmn**
7. Найдите раздел **Permissions** → подраздел **Repository permissions**.
   В длинном списке найдите строку **Contents** и справа от неё выберите
   **Read-only**.
8. Пролистайте вниз, нажмите **Generate token**.
9. На экране появится длинная строка, начинающаяся на `github_pat_`.
   **Скопируйте её и вставьте в блокнот** — GitHub покажет её только один раз.

---

# Шаг 2. Скачать и установить код

Откройте **терминал в Open WebUI**.

Скопируйте блок ниже, вставьте в блокнот и **замените слово `ВАШ_КЛЮЧ` на
строку из шага 1** (вместе со словом, кавычек и скобок не нужно). Затем
скопируйте получившееся и вставьте в терминал:

```bash
cd /tmp && rm -rf xlsx2bpmn && git clone https://ВАШ_КЛЮЧ@github.com/Djytnek/xlsx2bpmn.git
```

Должно закончиться строкой вида `Receiving objects: 100% ... done.`

Дальше — установка. Здесь заменять ничего не надо, копируйте как есть:

```bash
pip install /tmp/xlsx2bpmn || pip install --user /tmp/xlsx2bpmn
```

Должно закончиться строкой `Successfully installed xlsx2bpmn-1.1.0`.

> Если строка `Permission denied` промелькнула по дороге — так и задумано.
> Команда написана с запасным вариантом и доделает всё сама. Смотрите только
> на последнюю строку.

Ключ из шага 1 остался записан внутри скачанной папки. Уберите его оттуда —
скопируйте и вставьте:

```bash
rm -rf /tmp/xlsx2bpmn/.git
```

Команда ничего не выведет. Так и должно быть.

# Шаг 3. Проверить, что установилось

Скопируйте и вставьте:

```bash
python /tmp/xlsx2bpmn/selftest.py
```

Последняя строка должна быть:

```
ВСЁ ХОРОШО
```

Если она есть — код установлен правильно, можно идти дальше.

> **Запомните на будущее.** Если Open WebUI когда-нибудь обновят или
> перезапустят с нуля, установка пропадёт и «BPMN-схема» перестанет работать.
> Лечится повторением шагов 2 и 3.

# Шаг 4. Создать ключ доступа внутри Open WebUI

1. В Open WebUI нажмите на **своё имя слева внизу** → **Настройки**.
2. Откройте раздел **Аккаунт**.
3. Найдите блок **Ключи API**, нажмите **Показать**.
4. Нажмите **Создать новый ключ**.
5. Скопируйте строку, начинающуюся на `sk-`, **и вставьте в блокнот** —
   понадобится в шаге 7.

---

# Шаг 5. Создать модель-исполнитель

Это вспомогательная модель, которая будет составлять описание схемы.
Отдельная запись нужна ради одной настройки — объёма памяти модели.

Откройте **Рабочее пространство** → **Модели** → **+ Добавить модель**.
Заполняйте сверху вниз.

### Верх страницы

**Название модели** — скопируйте и вставьте:

```
bpmn-worker
```

**Базовая модель (от)** — нажмите на поле, в выпадающем списке выберите:

```
qwen3.6:27b-110k
```

**Описание** — скопируйте и вставьте:

```
Служебная. Работает внутри функции BPMN-схема. Напрямую не использовать.
```

**Добавить тег** — пропустите, ничего не вписывайте.

**Системный промпт** — **оставьте поле пустым.** Это важно: все указания
модели передаёт функция, и написанное здесь будет ей мешать.

### Расширенные параметры

Нажмите надпись **Расширенные параметры** — раскроется длинный список полей,
у всех написано «По умолчанию».

Найдите в этом списке четыре поля и поменяйте только их:

| Найдите поле | Поставьте значение |
|---|---|
| **num_ctx (Ollama)** | `16384` |
| **Температура** | `0` |
| **think (Ollama)** | выключить |
| **Потоковый вывод ответа** | выключить |

Все остальные поля — `top_p`, `top_k`, `max_tokens`, `min_p`,
`repeat_penalty`, `mirostat`, `num_gpu`, `keep_alive` и прочие — **не
трогайте**, пусть остаётся «По умолчанию».

> Поле **num_ctx** — самое важное на этой странице. Это объём памяти модели.
> Если оставить по умолчанию, модель не дочитает задание до конца, и схемы
> будут получаться обрезанными.

### Низ страницы

Ниже идут разделы **Промпты**, **Знания**, **Инструменты**, **Скиллы**,
**Действия**, блок **Возможности** с галочками, а также поля **Терминал**
и **Голос TTS**.

**Не трогайте здесь ничего.** Эта модель только пишет текст: ни знания, ни
инструменты, ни веб-поиск ей не нужны. Галочки оставьте как стоят.

Нажмите **Сохранить и создать** внизу страницы.

### Убрать её из общего списка

Модель служебная, обычным пользователям она ни к чему.

Вернитесь в **Рабочее пространство** → **Модели**, найдите строку
`bpmn-worker` и **выключите переключатель справа от неё**. Функция будет
обращаться к модели по имени, на её работу это не влияет.

# Шаг 6. Добавить функцию

1. Откройте **Панель администратора** → вкладка **Функции**.
2. Нажмите **+** в правом верхнем углу.
3. Откройте в новой вкладке браузера страницу:

```
https://github.com/Djytnek/xlsx2bpmn/blob/main/owui/bpmn_pipe.py
```

4. В правом верхнем углу окна с кодом нажмите значок копирования
   (два наложенных прямоугольника) — код скопируется целиком.
5. Вернитесь в Open WebUI и вставьте скопированное в большое поле кода,
   предварительно удалив оттуда всё, что там было.
6. Поле «Название» заполнится само — `BPMN-схема`.
7. Нажмите **Сохранить**.
8. В списке функций найдите строку `BPMN-схема` и **включите переключатель
   справа**. Без этого функция не появится в списке моделей.

---

# Шаг 7. Настроить функцию

Останьтесь в **Панель администратора** → **Функции**. Нажмите **шестерёнку**
рядом с `BPMN-схема` → **Настроить**.

Впишите значения. Первые три — скопируйте как есть, в четвёртое вставьте
ключ `sk-...` из шага 4, остальные обычно уже стоят правильно:

| Поле | Значение |
|---|---|
| **MODEL** | `bpmn-worker` |
| **BASE_URL** | `http://localhost:8080` |
| **API_PATH** | `/api/chat/completions` |
| **API_KEY** | ключ `sk-...` из шага 4 |
| **REPAIRS** | `2` |
| **TIMEOUT** | `600` |
| **OUTPUT_DIR** | `/app/backend/data/bpmn` |
| **SHOW_TABLE** | выключено |

Нажмите **Сохранить**.

---

# Шаг 8. Проверить, что всё работает

1. Откройте новый чат.
2. В списке моделей сверху выберите **BPMN-схема**.
3. Скопируйте текст ниже, вставьте в чат и отправьте:

```
Заявка на отпуск поступает в отдел кадров. Кадровик проверяет остаток дней.
Если дней хватает, руководитель согласует заявление, после чего кадровик
вносит приказ. Если не хватает, сотруднику отправляют отказ.
```

**Что должно произойти.** Сверху пробегут строчки «Читаю описание процесса…»,
«Рисую схему…», «Готово». Затем появится картинка схемы: рамка с названием
организации, внутри неё полосы ролей, в полосах — шаги процесса со стрелками.
Ниже — перечень шагов и имена сохранённых файлов.

4. Проверьте правку словами. Отправьте следующим сообщением:

```
добавь после согласования уведомление сотруднику
```

Схема должна перерисоваться с новым шагом.

Получилось — установка закончена.

# Если что-то пошло не так

| Что вы видите | Что делать |
|---|---|
| При скачивании: `Authentication failed` | Ключ из шага 1 скопирован не полностью или просрочен. Сделайте новый |
| При скачивании: `Repository not found` | У вашей учётной записи нет доступа к хранилищу. Попросите владельца добавить вас |
| При установке: `Permission denied` | Так и должно быть, вторая половина команды из шага 2 всё доделает. Смотрите на последнюю строку: нужна `Successfully installed` |
| `selftest.py` не заканчивается словами `ВСЁ ХОРОШО` | Повторите шаг 2 целиком |
| В списке моделей нет «BPMN-схема» | Не включён переключатель функции: шаг 6, пункт 8 |
| «Не найден файл prompt.md внутри пакета» | Повторите шаги 2 и 3 |
| «Не получилось обратиться к модели» | Проверьте MODEL, BASE_URL и API_KEY в шаге 7 |
| Ошибка `401` или `403` | Ключ `sk-...` недействителен. Сделайте новый по шагу 4 и впишите в шаг 7 |
| Схема обрывается на середине | Не выставлен `num_ctx`. Вернитесь в шаг 5 и поставьте `16384` |
| Схема строится дольше минуты | Модель тяжела для этого сервера. В шаге 5 смените базовую модель на `gemma4:26b` и сохраните |
| «Не получилось собрать схему» | Это не поломка. Описание процесса можно понять по-разному. Допишите, что происходит после каждого шага и чем всё заканчивается |
| Картинки нет, а текст и файлы есть | Ваша версия Open WebUI не показывает встроенные картинки. Файлы `.svg` при этом сохраняются, смотрите ниже |
| Всё перестало работать после обновления | Повторите шаги 2 и 3 |

# Где лежат готовые файлы

Каждая схема сохраняется тремя файлами в папке `/app/backend/data/bpmn`.
Посмотреть список — вставьте в терминал:

```bash
ls -la /app/backend/data/bpmn
```

- `.bpmn` — открывается в BPMN-редакторе, например на demo.bpmn.io
- `.svg` — картинка, открывается в браузере и вставляется в документы
- `.txt` — таблица процесса, из которой собрана схема
