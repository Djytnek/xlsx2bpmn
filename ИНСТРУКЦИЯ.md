# Инструкция: из документа — в схему

Здесь описан весь путь целиком: у вас есть регламент в Word или PDF, а нужна
схема процесса. Делать будете вы, а таблицу за вас составит нейросеть.

Путь такой:

```
Регламент.docx  →  Регламент.md  →  таблица.txt  →  Схема.png
   ваш файл        превратили       составила        нарисовала
                  в простой текст     нейросеть        утилита
```

Ошибки в таблице неизбежны — нейросеть ошибается. Это не беда: утилита сама
скажет, что не так, вы скопируете её слова нейросети, и та исправит. Так
по кругу, пока не получится. Обычно хватает одного-двух заходов.

---

# Часть 1. Установка. Делается один раз

Если вы уже ставили утилиту по [НАЧАЛО.md](НАЧАЛО.md) — почти всё готово,
но проверьте последний шаг этой части: для работы с Word и PDF нужно
дополнение.

## 1.1. Проверить Python

```bash
python3 --version
```

Должно ответить `Python 3.10` или больше.

## 1.2. Скачать проект

```bash
cd ~
git clone https://github.com/Djytnek/xlsx2bpmn.git
```

## 1.3. Установить вместе с дополнением для Word и PDF

```bash
python3 -m pip install --user "$HOME/xlsx2bpmn[docs]"
```

Обратите внимание на `[docs]` в конце — именно оно приносит чтение `.docx`
и `.pdf`. **Ставится долго, несколько минут, и весит около 300 МБ.**

> Ответило `error: externally-managed-environment`? Ничего не установилось.
> Повторите ту же команду с добавкой:
> `python3 -m pip install --user --break-system-packages "$HOME/xlsx2bpmn[docs]"`

## 1.4. Разрешить запуск команд по имени

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && export PATH="$HOME/.local/bin:$PATH"
```

Ответом будет тишина — так и должно быть.

## 1.5. Проверить

```bash
xlsx2bpmn --version
markitdown --help
```

Первая команда должна ответить номером версии, вторая — показать подсказку
про `markitdown <FILENAME>`. Если обе ответили — установка удалась.

# Часть 2. Работа. Пять шагов

Дальше показан живой пример: регламент согласования договора. Ваши файлы
будут называться иначе, всё остальное — так же.

## Шаг 1. Превратить документ в простой текст

Нейросеть не умеет читать `.docx` и `.pdf` напрямую. Превращаем документ
в markdown — это обычный текст:

```bash
cd ~
markitdown Регламент.docx > Регламент.md
```

Проверьте, что получилось:

```bash
cat Регламент.md
```

Должен появиться текст вашего регламента:

```
Регламент согласования договора

1. Менеджер готовит проект договора и передаёт его юристу.
2. Юрист проверяет договор. Если есть замечания, договор возвращается
   менеджеру на доработку.
3. Если замечаний нет, договор уходит на подпись директору.
4. Директор подписывает договор, после чего процесс завершён.
```

Работает так же с `.pdf`, `.pptx`, `.xlsx`, `.html`. Команда одна, меняется
только имя файла.

> **Вышло пусто?** Значит документ — скан, картинка в оболочке Word. Текста
> внутри нет, и взять его неоткуда: описание придётся набрать руками
> в любом текстовом файле. Дальше всё то же самое.

## Шаг 2. Взять промпт

Промпт — это готовое задание для нейросети, где расписано, какой должна быть
таблица. Он лежит в проекте:

```bash
cat ~/xlsx2bpmn/xlsx2bpmn/prompt.md
```

Скопируйте его целиком. В самом начале промпта есть два места в двойных
фигурных скобках — их нужно заменить на свои:

| Что заменить | На что |
|---|---|
| `{{INPUT_MD}}` | `Регламент.md` — файл из шага 1 |
| `{{OUTPUT_TXT}}` | `таблица.txt` — как назвать результат |

## Шаг 3. Отдать промпт нейросети

Дальше зависит от того, какой нейросетью вы пользуетесь.

**Если она умеет работать с файлами** (Claude Code и подобные) — вставьте
промпт с подставленными именами, и она сама прочитает `Регламент.md`
и запишет `таблица.txt`.

**Если это обычный чат в браузере** — вставьте промпт, а следом текст
регламента из шага 1. Нейросеть покажет таблицу в ответе. Скопируйте её
и сохраните в файл:

```bash
nano таблица.txt
```

Вставьте таблицу, нажмите `Ctrl+O`, `Enter`, `Ctrl+X`.

> **Важно:** в файле должна быть только таблица. Никаких пояснений вроде
> «Вот ваша таблица:» и никаких знаков ``` — их нужно убрать.

Выглядеть она должна примерно так:

```
id|name|type|pool|lane|next|message_to|data_in|data_out
s|Нужен договор|startEvent|ООО «Ромашка»|Менеджер|t1|||
t1|Подготовить проект договора|userTask|ООО «Ромашка»|Менеджер|t2|||
t2|Проверить договор|userTask|ООО «Ромашка»|Юрист|g1|||
g1|Есть замечания?|exclusiveGateway|ООО «Ромашка»|Юрист|t1 [Да]; *t3 [Нет]|||
t3|Подписать договор|userTask|ООО «Ромашка»|Директор|e|||
e|Договор подписан|endEvent|ООО «Ромашка»|Директор||||
```

## Шаг 4. Отдать таблицу утилите

```bash
xlsx2bpmn таблица.txt -o Схема.png
```

**Получилось** — увидите строку, начинающуюся с `OK`:

```
OK -> Схема.png  элементов 6, потоков 6, сообщений 0, пулов 1, раскладка: bpmn-auto-layout
```

Рядом лежит готовая картинка. Откройте её двойным щелчком. **Готово,
дальше можно не читать.**

**Не получилось** — увидите строки со словом `ERROR` и итог внизу:

```
таблица.txt: [строка 6] ERROR next ссылается на несуществующий id 'end'
таблица.txt: [строка 6] WARN  у 't3' нет исходящих потоков
таблица.txt: [строка 7] WARN  у 'e' нет входящих потоков
таблица.txt: не сконвертировано — ошибок 1
```

Тогда шаг 5.

> `WARN` — это замечания, они не мешают. Схема не собирается только
> из-за `ERROR`.

## Шаг 5. Отдать ошибки обратно нейросети

Скопируйте **все строки с ошибками целиком** и напишите нейросети примерно
так:

```
Утилита не приняла таблицу и ответила:

таблица.txt: [строка 6] ERROR next ссылается на несуществующий id 'end'
таблица.txt: не сконвертировано — ошибок 1

Исправь таблицу и пришли её целиком.
```

Нейросеть увидит, в какой строке ошибка и какая именно — сообщения написаны
понятным языком, специально для этого. Она пришлёт исправленную таблицу.

Замените ею содержимое `таблица.txt` и **вернитесь на шаг 4**.

Так по кругу, пока не появится `OK`. В примере выше нейросеть написала `end`
вместо `e` — после исправления одной буквы схема собралась.

# Что ещё умеет утилита

Когда основное заработает, пригодится:

```bash
xlsx2bpmn таблица.txt              # файл .bpmn для редактора схем
bpmn2xlsx Схема.bpmn               # обратно: из схемы в таблицу
xlsx2bpmn таблица.txt --all-levels # папка со всеми уровнями процесса
```

Файл `.bpmn` можно перетащить на сайт demo.bpmn.io или открыть в Camunda
Modeler и править схему мышкой.

Подробности про колонки таблицы — в [НАЧАЛО.md](НАЧАЛО.md), про всё
остальное — в [README.md](README.md).

# Если что-то пошло не так

| На экране | Что делать |
|---|---|
| `markitdown: command not found` | дополнение не установлено. Шаг 1.3, с `[docs]` в конце |
| `xlsx2bpmn: command not found` | шаг 1.4 про `PATH` |
| `error: externally-managed-environment` | повторить установку с `--break-system-packages` |
| `В текстовом файле не найден разделитель '\|'` | нейросеть отдала таблицу в другом виде. Попросите: «колонки разделяй вертикальной чертой, без markdown-разметки» |
| `в пуле 'X' нет startEvent` | в таблице нет строки начала процесса. Отдайте ошибку нейросети |
| `не сконвертировано — ошибок N` | это итог, сами ошибки — в строках выше. Копируйте их все |
| в файле оказались строки вроде «Вот таблица:» | уберите всё, кроме самой таблицы |

Ничего испортить нельзя: утилита только читает вашу таблицу и создаёт новые
файлы рядом.
