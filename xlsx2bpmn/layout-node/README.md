# Раскладчик на bpmn-auto-layout

Ставить ничего не нужно: `bundle.mjs` — это сам bpmn-auto-layout, собранный
в один файл вместе со всеми зависимостями. Он едет вместе с пакетом и
работает сразу после `pip install`, без `npm install` и без сети.

Единственное требование — **Node.js 20 или новее** в системе. Если его нет,
схемы разложит встроенный раскладчик на Python, и утилита об этом скажет.

**Он не понимает дорожки.** `laneSet` срезается перед вызовом, элементы
расставляются без оглядки на роли, а полосы потом проводятся приблизительно
по фактическому расположению — задача может оказаться в чужой полосе.
Поэтому по умолчанию его берут только для процессов **без дорожек**;
где дорожки есть, работает встроенный. Выбор делается сам, отдельно для
каждого пула.

Взять принудительно: `--layout node`.

## Файлы

| Файл | Что это |
|---|---|
| `bundle.mjs` | готовый к запуску раскладчик, зависимостей не требует |
| `cli.mjs` | тот же вход, но через `node_modules` — для разработки |
| `package.json` | зависимости для `cli.mjs` |
| `THIRD-PARTY.md` | лицензии всего, что зашито в `bundle.mjs` (всё MIT) |

## Пересобрать bundle.mjs

Нужно, только если обновляете bpmn-auto-layout:

```bash
cd xlsx2bpmn/layout-node
npm install
npx esbuild cli.mjs --bundle --platform=node --format=esm \
    --legal-comments=inline --outfile=bundle.mjs
```

`--legal-comments=inline` обязателен: он сохраняет копирайты внутри файла,
как того требует MIT. После пересборки обновите `THIRD-PARTY.md`.
