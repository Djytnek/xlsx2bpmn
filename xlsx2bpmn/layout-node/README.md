# Необязательный раскладчик на bpmn-auto-layout

Ставится отдельно и только если нужен:

```bash
cd ~/.xlsx2bpmn/layout-node   # либо xlsx2bpmn --setup-layout
npm install
```

После этого доступен ключ `--layout node`.

**Он не понимает дорожки.** `laneSet` срезается перед вызовом, элементы
расставляются без оглядки на роли, а полосы потом проводятся приблизительно
по фактическому расположению — и могут наезжать друг на друга.

Берите его, если у схемы **нет дорожек**: главную линию он проводит ровнее.
Если дорожки есть — оставайтесь на встроенном (`--layout native`).
