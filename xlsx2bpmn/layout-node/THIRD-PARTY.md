# Сторонний код внутри bundle.mjs

Файл `bundle.mjs` — раскладчик bpmn-auto-layout, собранный в один файл
вместе с зависимостями, чтобы он работал без `npm install`.
Всё перечисленное распространяется по лицензии MIT; её текст приведён
ниже целиком, как MIT и требует.
